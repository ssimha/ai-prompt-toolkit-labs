# Prompt 4 — Scenario Modeling (section 3.7)

```
Model this scenario: raw material costs increase 10% starting next
quarter, with no other changes to volume, pricing, or other cost
lines. Hold all other Q2 figures constant at current levels
(consolidated Q2 COGS: $3,865,670.00).

Calculate:
1. The resulting COGS for Q3 if this is the only change
2. The resulting change in dollar terms
3. State explicitly every assumption you made beyond what's specified
   above

Do not assume any offsetting price increase or volume change unless
I've told you to model one.
```

Check section 3 of the output carefully — a model that silently
assumes something you didn't specify (e.g., that the 10% applies only
to some subsidiaries, or that volume grows alongside cost) has failed
the actual point of this exercise, even if the arithmetic is correct.
