# Prompt 5 — Few-Shot Report Conventions (section 3.8)

```
Match this exact commentary style used in prior board decks:

Example: "Gross margin was 34.2% (down 1.8 points from Q1). The
decline was driven primarily by a $340K increase in raw material
costs at the Ohio plant, partially offset by a $110K reduction in
labor costs following the automation upgrade completed in March."

Now write commentary for the COGS variance discussed above (Texas and
Ohio as primary drivers, per Prompt 2), in this exact style.
```

Compare against the example: short declarative sentences, dollar
figures followed by percentage or point changes in parentheses, no
unsupported editorializing about whether the result is "good" or "bad."
