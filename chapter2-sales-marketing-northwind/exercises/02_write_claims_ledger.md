# Exercise 2 — Write a Claims Ledger From Scratch

Northwind is launching a new feature: automated project templates
(pre-built project structures for common workflows like client
onboarding or product launches).

Write a claims ledger entry for this feature, following the exact
format in `claims/claims_ledger.md` — an approved exact wording, plus
an explicit list of adjacent claims that are NOT approved (tempting
exaggerations someone on the marketing team might reach for).

Then write a short cold-email paragraph promoting the feature using
ONLY your ledger entry, and run it through
`claims/claims_checker.py` (you'll need to save your paragraph as a
.txt file first) to sanity-check it against the mechanical patterns,
even though this is a new claim the checker's ledger cross-check list
doesn't specifically know about yet.
