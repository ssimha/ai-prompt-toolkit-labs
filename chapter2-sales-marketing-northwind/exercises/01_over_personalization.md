# Exercise 1 — Catch the Over-Personalization Line

Below is a real (invented) trial-activity data point: a prospect logged
into Northwind at 11:47pm, 12:03am, and 11:20pm on three consecutive
nights.

Generate a nurture email referencing this activity two different ways:

**Version A:** explicitly mention the late-night login times ("I
noticed you've been logging in past 11pm a few nights this week...")

**Version B:** reference the underlying need without citing the
specific behavioral data ("if you're squeezing project setup into a
packed schedule, here's a shortcut...")

Read both out loud as if you were the recipient. Which one reads as
helpful, and which reads as being watched? Write down, in your own
words, where you'd draw the line between personalization that uses
behavioral data usefully and personalization that discloses it in a
way that feels invasive — section 2.8 names the failure mode but
deliberately doesn't give you a hard rule, because the line depends on
what's being disclosed, not just that something was.
