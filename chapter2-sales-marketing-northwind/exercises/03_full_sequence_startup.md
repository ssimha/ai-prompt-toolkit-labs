# Exercise 3 — Build a Full 5-Email Sequence for the Startup Segment

Using every technique in this chapter, build a complete 5-email trial
nurture sequence for the startup segment profile in
`brand-voice/segments.md`:

1. Outline all 5 emails first (Prompt 3, step 1) before drafting any of them
2. Draft each from its approved outline (Prompt 3, step 2)
3. Generate subject line variants for at least 2 of the 5 (Prompt 4)
4. Run the claims ledger check on all 5 (Prompt 6) — the startup
   segment's low concern for permissions/audit-trail features makes it
   an easy segment to accidentally over-promise enterprise-tier
   capabilities to, so check carefully
5. Output the final sequence as structured JSON (Prompt 5) and validate
   it with `expected-output/validate_campaign_json.py`

You should end this exercise with a validated JSON file and a written
note on which claims-ledger issues, if any, you had to fix along the way.
