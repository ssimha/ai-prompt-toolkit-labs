# Prompt 4 — A/B Variant Generation With Named Dimensions (section 2.6)

```
Generate 3 subject line variants for the email below, each testing a
different angle:
Variant A: curiosity-driven, no specific benefit named
Variant B: direct benefit statement
Variant C: question format, referencing their specific in-app activity

Keep each under 50 characters. Return as a labeled list, not prose.
```

Compare this against just asking for "3 subject line options" with no
named dimensions — notice how much more differentiated the results are
when each variant is testing something specific.
