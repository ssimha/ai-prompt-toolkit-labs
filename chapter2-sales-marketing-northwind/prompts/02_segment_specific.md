# Prompt 2 — Segment-Specific Prompting (section 2.4)

Pick a segment from `brand-voice/segments.md` and fill in the template:

```
Write a trial-day-3 nurture email for this segment:

Segment: {segment name}
Primary concern: {from segments.md}
What they've done in-app: {from segments.md}
Tone: reference the brand-voice examples from prompts/01

The email should nudge them toward inviting a teammate, and should
mention the segment's top-concern feature naturally — don't force it
if it breaks the flow of the message.
```

Try this for all three segments and compare the results side by side.
They should differ meaningfully in what they emphasize, not just in
which segment name is mentioned.
