# Prompt 3 — Prompt Chaining: Outline, Draft, Variants (section 2.5)

Run these three steps in sequence, reviewing the output of each before
moving to the next.

**Step 1 — outline only:**
```
Outline the argument structure for a trial-day-3 email to the
enterprise segment described in brand-voice/segments.md. Just the
beats — opening hook, the core value point, the call to action — one
line each. No prose yet.
```

**Step 2 — draft from the approved outline:**
```
Write the full email following this exact outline: {paste your
approved outline here}. Match the brand voice from prompts/01.
```

**Step 3 — variants from the approved draft:**
```
Generate two alternate subject lines and one alternate opening line
for the email below, keeping the body unchanged: {paste your approved
draft here}
```

Notice how much easier it is to redirect a bad structural choice at
Step 1 than after a full polished draft already exists at Step 2.
